## Constraints

| ID | Constraint |
| --- | --- |
| C-01 | **`LEMMINGS/` is evidence and is never modified.** Runs, patches and experiments work on a copy under `tools/dev/builds/`, never on `LEMMINGS/`: a Hatari GEMDOS drive pointed at `LEMMINGS/` would let anything the loader or the game writes land in the evidence. `LEMMINGS.sha256` is the check: `shasum -a 256 -c LEMMINGS.sha256` passes before and after every run. The first pass broke this rule: it left a patched `START.TOS` in place, with the original as `START.TOS.orig`. |
| C-02 | **Hatari's code is not modified.** Diego, 2026-10-11. Hatari is used as released (2.6.1 here), through its command-line options, configuration, control socket and debugger; `../hatari` is read to understand its behaviour, never patched or rebuilt for this project. Every fix lives on the Atari side: in the launcher, in a program or driver run before it, or in the files on the drive. |
| C-03 | **No third-party binaries are committed**: TOS ROMs, hard-disk drivers (AHDI, HDDriver, PP's driver), disk images. Their paths live in `tools/dev/dev.cfg`, which is git-ignored; the PPDRIVER boot blob is used from `../atari-hd` (D-09). TOS images already on this Mac, in the firmware checkout and not committed there either: `../sidecartos/Atari ST TOS Images /` (TOS 1.00 to 1.04; the trailing space is part of the name), `../sidecartos/Atari STE TOS Images/` (1.06, 1.62, 2.05, 2.06) and `../sidecartos/TOS/` (80 images, among them TT TOS 3.06, Falcon TOS 4.04 and 4.92, EmuTOS 1.3.0). |
| C-04 | **The target needs at least 1 MB and a supported driver.** `LEMMINGS/README.TXT` (PP, May 2011): any ST, STE, Mega ST, Mega STE or Falcon with at least 1 MB, "PP, AHDI or Hddriver", a partition under 512 MB; on the Falcon, start from ST medium resolution. Every emulator run uses at least 1 MB and records its RAM size. |
