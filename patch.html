Patch a game

Give this page a game's ZIP exactly as you downloaded it from the 8bitchip.info website. The page checks that it is one of the downloads it knows, tells you whether the game runs from GEMDOS and GEMDRIVE as it is, and when a fix makes it run, patches the ZIP and gives it back to you. Everything happens in your browser: your file is not sent anywhere.

?

Choose the game's ZIP

Drop it here, or choose it.

Then

  1. Unpack the ZIP the page gave you, or the original when there is nothing to patch.
  2. Copy the game's folder to your GEMDOS drive: the folder Hatari serves as drive C:, or the microSD card of the SidecarTridge Multidevice, which GEMDRIVE serves.
  3. Start the game's program from that folder, as the page says. A fix that adds GDBPB.PRG needs it run first, once after each reset or power-on.

The page holds no file of the games. It rebuilds the fixed file from your own copy, and checks the result against this project's build before it gives it to you. How each fix works: the solutions.

The adaptations, their list and their documentation come from a third party website. This site links to its pages and copies none of its files. Every run was made in Hatari 2.6.1 and SidecarTridge Multi-device with the Multidrive Emulator. Atari, ST, STE, TT, Falcon and TOS are Atari's names.
